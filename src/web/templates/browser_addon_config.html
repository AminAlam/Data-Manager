Installation Instructions
  1. Download the browser extension using the button above
  2. Unzip the downloaded file
  3. In Chrome, go to chrome://extensions/
  4. Enable "Developer mode" (toggle in the upper right)
  5. Click "Load unpacked" and select the unzipped extension folder
  6. Click on the extension icon in your browser toolbar
  7. Enter your username and API key
  8. Click Save to complete the setup
