# Data Manager - Google Drive Integration

A browser extension that integrates with Data Manager to easily add Google Drive documents to your database.

## Features

- Add Google Docs, Sheets, and Slides directly to Data Manager
- Automatically extract document information
- Simple configuration
- Works with existing Data Manager authentication

## Installation

### Developer Mode

1. Download this extension folder
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" (toggle in the upper right)
4. Click "Load unpacked" and select the downloaded extension folder

### Configuration

1. Click on the extension icon in your browser toolbar
2. Enter your Data Manager server URL, username, and API key
3. Click Save

## Getting Your API Key

1. Log in to your Data Manager
2. Go to your profile page
3. Click "Configure Browser Add-on"
4. Click "Generate API Key"
5. Copy the displayed API key

## Usage

1. Navigate to any Google Doc, Sheet, or Slide
2. Click the extension icon in your browser toolbar
3. The document information will be automatically filled in
4. Add any tags and notes
5. Click "Add to Data Manager"

## Permissions

This extension requires:
- Access to Google Drive domains (docs.google.com, sheets.google.com, slides.google.com)
- Storage permission to save your configuration
- ActiveTab permission to interact with the current page
